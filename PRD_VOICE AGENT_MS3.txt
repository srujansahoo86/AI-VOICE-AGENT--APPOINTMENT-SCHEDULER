1. What You Are Building
A deployed voice agent that lets a user book a tentative advisor appointment over a phone-style conversation — without collecting any personal information during the call. Your instructor gets a live URL they can open and test.

The agent must:
Greet the user and state it does not give investment advice
Detect what the user wants (book / reschedule / cancel / prepare / availability)
Collect a topic and preferred date/time
Offer backend-generated slots in IST
Confirm the slot and generate a booking code (e.g. NL-A742)
Trigger all three MCP actions (calendar hold, sheets/notes append, and Gmail draft)
Block PII and investment advice — always

The one rule that matters most
The LLM must NEVER invent slots, times, or booking codes.
All data comes from the backend. The LLM only handles conversation.

4. The Conversation Flow (Happy Path)
Follow this sequence for every new booking. Do not skip steps.

Happy Path — Step by Step
Step 1   GREETING         Welcome + compliance disclaimer
Step 2   INTENT           Detect what the user wants
Step 3   TOPIC            Confirm topic from the approved list
Step 4   DATE / TIME      Ask for preferred date and time
Step 5   SLOTS            Offer 2 backend-generated slots in IST
Step 6   CONFIRM          User picks a slot — repeat it back before confirming
Step 7   BOOKING CODE     Backend generates NL-XXXX code
Step 8   MCP ACTION       Fire calendar hold or notes append
Step 9   WRAP UP          Confirm booking, give secure link, say goodbye

Greeting Script
Use this exactly
"Welcome to the Advisor Appointment Scheduler.
 This call is informational only and does not provide investment advice.
 How may I assist you today?"

Slot Confirmation Script
Repeat before confirming — mandatory
"To confirm: your tentative advisor session for [TOPIC]
 is scheduled for [DAY] at [TIME] IST. Shall I confirm this?"

5. Compliance — The Two Hard Rules
Rule 1 — No PII During the Call
The agent must NEVER ask for or accept: phone numbers, email, PAN, Aadhaar, account numbers, portfolio details.

If the user volunteers PII, interrupt immediately:
"Please do not share personal or financial information during this call.
 You will receive a secure link to complete your details safely."

Rule 2 — No Investment Advice
Mandatory refusal:
"I cannot provide investment advice.
 You may review educational resources from SEBI (sebi.gov.in) or Investor.gov."

6. Slots and Booking Code
Slot Generation
Slots come from your backend — never from the LLM. Offer exactly 2 slots.
Example slot output
"Available slots are:
  Friday 3:00 PM IST
  Friday 5:30 PM IST
 Which works for you?"

Booking Code
Format: NL-XXXX
code = "NL-" + random_alphanumeric(4).upper()
Example: NL-A742, NL-K391, NL-B827
Generate AFTER user confirms — never before.

7. MCP Integration
You need all THREE working MCP actions integrated.

MCP Action
What It Does
Google Calendar hold
Create event: "Advisor Q&A — SIP/Mandates — NL-A742" as tentative
Notion / Google Sheets append
Append row: { date, topic, slot, code } to bookings sheet
Gmail draft
Draft an internal approval email — do NOT auto-send

8. Timeout & Interruption
Silence Timeout
4 seconds silence: "Are you still there?"
Another 4 seconds: "I'll end the session now. Please call back when ready. Goodbye."

Mid-Sentence Interruption
User interrupts a slot offer: stop, return to date/time collection
Do not repeat what you already said — just ask the new question

10. Deployment Guide — Get Your Shareable URL
Follow these steps in order. You will have a live link in under 2 hours.

Step 1 — Prepare Your GitHub Repo
Repo structure
your-repo/
  main.py           (FastAPI app — slots, booking code, MCP trigger)
  requirements.txt  (fastapi, uvicorn, httpx, google-auth, ...)
  .env.example      (list env vars needed, never commit real keys)
  README.md         (include your Antigravity agent link here)

Push everything to a public GitHub repository
Never commit .env files or API keys — use environment variables
Add a requirements.txt with all dependencies listed explicitly

Step 2 — Deploy Backend on Render
Render free tier is sufficient for a bootcamp demo
1.  Go to render.com and sign up with your GitHub account
2.  Click New > Web Service
3.  Connect your GitHub repo
4.  Set these fields:
      Name:          voice-agent-backend
      Runtime:       Python 3
      Build Command: pip install -r requirements.txt
      Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT
5.  Add environment variables in the Render dashboard:
      GEMINI_API_KEY
      GOOGLE_CALENDAR_CREDENTIALS  (or NOTION_TOKEN)
      Any other secrets your app needs
6.  Click Deploy — Render builds and gives you a URL like:
      https://voice-agent-backend.onrender.com

Important — Render free tier cold starts
On the free tier, Render spins down your service after 15 minutes of inactivity.
The first request after a cold start takes 30-50 seconds.
Fix: ping your backend URL once before your demo starts.
Or upgrade to Render Starter ($7/month) to keep it always-on.

Step 3 — Set Up Your Voice Agent on Antigravity
Antigravity gives you a shareable voice UI link automatically
1.  Go to Google AI Studio and open Antigravity
2.  Create a new voice agent project
3.  Set your system prompt (see Section 4 conversation flow)
4.  Point the backend webhook to your Render URL:
      Slot endpoint:    https://voice-agent-backend.onrender.com/slots
      Booking endpoint: https://voice-agent-backend.onrender.com/book
      MCP endpoint:     https://voice-agent-backend.onrender.com/mcp
5.  Test the full flow inside Antigravity
6.  Click Share — Antigravity generates a public link like:
      https://aistudio.google.com/live/agent/YOUR_AGENT_ID

Step 4 — What to Send Your Instructor
Include all three in one message
1.  Live agent URL (Antigravity shareable link) — this is the main link
2.  Backend API URL (Render) — shows your backend is real and deployed
3.  GitHub repo link — shows your code, README, and architecture

Example message to instructor:
  "Here is my voice agent prototype:
   Voice UI:   https://aistudio.google.com/live/agent/XXXX
   Backend:    https://voice-agent-backend.onrender.com
   Code:       https://github.com/yourusername/voice-agent
   Demo guide: README.md lists the 6 scenarios to test"

11. FastAPI Backend — Minimum Endpoints
Your FastAPI app needs these 3 endpoints for the voice agent to work.

Endpoint
What It Does
When Called
GET  /slots
Returns 2 available slots for a given day
Called after user gives date preference
POST /book
Generates NL-XXXX booking code, fires MCP action
Called after user confirms slot
POST /mcp
Triggers Google Calendar hold, Google Sheets append, and Gmail draft
Called from /book internally

Minimal /slots response (hardcode for demo)
GET /slots?day=friday

Returns:
{
  "slots": [
    "Friday 3:00 PM IST",
    "Friday 5:30 PM IST"
  ]
}

You can hardcode a fixed slot list for the demo — it just needs to work.

Minimal /book response
POST /book
Body: { "topic": "SIP/Mandates", "slot": "Friday 3:00 PM IST" }

Returns:
{
  "booking_code": "NL-A742",
  "secure_link": "https://advisor.example.com/complete/NL-A742",
  "mcp_status": "calendar_hold_created"
}
